# S2 — Kavita SignalR events and reader behaviour

Script `spikes/s2_kavita_signalr.py` (needs `signalrcore`; venv `~/readsync-work/venv`). Raw events: `S2.json`.

## Findings (API half)
- Hub: `wss://<kavita>/hubs/messages`, JWT as `access_token` (from `POST /api/Plugin/authenticate?apiKey=…&pluginName=…` → `token`). Connects fine; on connect it sends `OnlineUsers` `[["thehusk"]]`.
- `UserProgressUpdate` payload: `{"body":{"userId":1,"seriesId":90,"volumeId":90,"chapterId":102,"pagesRead":5},"name":"UserProgressUpdate","title":"Updating User Progress","eventType":"updated"}`.
  **It carries `pagesRead` only: no `bookScrollId`, no percentage.** The spoke must re-read `GET /api/Reader/get-progress?chapterId=` after each event.
- **Echo (R8): our own REST writes DO fire the event**, 0.04–0.2 s after `POST /api/Reader/progress`. The event has no origin field, so the hub must suppress echoes itself (remember the last value written per chapter for a few seconds).
- **`AnnotationUpdate` did not fire** for an annotation created and deleted through `POST /api/Annotation/create` / `DELETE /api/Annotation` (2 runs, 4–8 s wait each). Either it only fires for UI-originated changes or to other users. Do not depend on it: poll `GET /api/Annotation/all-for-series` (cheap) for the annotation spoke. Re-check once with the owner creating a highlight in the browser (step 3 below).
- Annotation create needs these `AnnotationDto` fields or it returns 400 "missing required properties": `ownerUserId` (1) and `ownerUsername` ("thehusk"), in addition to `xPath`, `endingXPath`, `selectedText`, `pageNumber`, ids, `highlightCount`, `selectedSlotIndex`, `containsSpoiler`, `comment`. With those, create returned 200 and delete 200 (ids 4, 5; both removed, series has 0 annotations again).
- Side effect: restoring "no progress" is not possible through the API. Time War had no progress record (`pageNum 0, lastModified 0001-01-01`); after the test it has an explicit `pageNum 0` record. Harmless, but the spoke must not treat "a progress row exists" as "was opened".
