# S4 — Whisper-clip lookup without a map (2026-10-30)

10/10 clips located from the clip text alone, matching S3's map (gate: 9/10). Script `spikes/s4_clip_lookup.py`, rows in `S4.json`.

## Method
Same 10 timestamps as S3 (seed 7). Each 20 s clip → Whisper shim (text only) → fuzzy search (`rapidfuzz.partial_ratio`, windows of ~1.3× clip length, step ¼ window) over
±10 % of the ebook text centred on `t / total` (what a player knows: roughly how far through the audio it is). Agreement = found position within 1,500 chars of the S3 map's position.

## Results
- Genuine hits: score 88.4–98.2, distance from the map 9–65 chars (≈ one sentence). Runner-up (a non-overlapping window) 45–50, **margin 43–51**.
- So a usable confidence gate for the ABS-bookmark fallback: **score ≥ 80 and margin ≥ 30**. Nothing real came close to either line.
- The ±10 % window matters: it needs a rough position. With no position at all the whole-book search is 10× bigger and the margin shrinks; not measured here (every real case has a position).

## Hard cases (D2)
| Case | Heard | Result |
|---|---|---|
| Intro/credits at t = 2 s | "Simon & Schuster Audio presents … Read by …" | **Fails safely**: best 46.4 = runner-up 46.4, margin 0 → gate rejects it. No text in the ebook matches the credits. |
| First second of file 15 (chapter opening) | Normal prose | Located exactly (3 chars off, margin 47). A chapter start that is prose is not hard. |

Not covered: a clip that is silence/music only (Whisper returns empty text → `locate` returns None → treated as "no match", the same as the credits case), and chapter announcements ("Chapter 12") that the ebook also prints; both need a real book with such audio.

## Consequence for the plan
Map-first, clip-fallback (Task 22) is sound: when a bookmark falls in a region without a map, a clip lookup works if gated on score + margin, and rejects credits/silence instead of guessing. Cost: one Whisper call (~1–2 s on the shim) + a few ms of fuzzy search.
